# 场景用字的篆书字帖补录

## 7 组异写复核

| 样本释字与旧标签 | 核对结果及本次字例 |
| --- | --- |
| 崐／崑 | 《说文广义》卷二第 198 页旧字框的释义为崑崙山名。本次补俞和帖中的「崐」。[教育部字典](https://dict.variants.moe.edu.tw/dictView.jsp?ID=12379&q=1) |
| 敕／勑 | 字典记录「勑」可作「敕」的异体。《说文广义》卷十二第 180 页 3 条旧标注所在原栏释「勞也」，读 lài，须保留该字义。本次补俞和帖中「束、攴」结构的「敕」。[教育部字典](https://dict.variants.moe.edu.tw/dictView.jsp?ID=59490&q=1) |
| 槁／槀 | 《说文广义》卷十第 96 页 6 条旧框对应木部「槀」。卷三第 87 页另 6 条旧标签「槀」，原字头定位在前一页第 86 页，注明从禾，实为「稾」。本次补俞和帖中馆释「槁」的一例，原形为高上木下。[教育部字典](https://dict.variants.moe.edu.tw/dictView.jsp?educode=A01992) |
| 牋／箋 | 《说文广义》卷十第 213 页 5 个旧框释「箋」，与「牋」同义异体。本次补俞和帖中用片旁的「牋」。[教育部字典](https://dict.variants.moe.edu.tw/dictView.jsp?ID=32454&q=1) |
| 迺／廼 | 《峄山刻石》的「廼」位于「莫能禁止」之后，与「迺」为同词异写。本次补吴昌硕《篆书八言联》的「迺」。[教育部字典](https://dict.variants.moe.edu.tw/dictView.jsp?ID=-45186) · [吴昌硕原幅](https://www.dpm.org.cn/collection/handwriting/231408.html) |
| 璽／壐 | 《说文广义》卷六第 111 页旧例可核从土的「壐」，原栏释「王者印也」。本次补池永榮春《聯珠篆文》第 65 扫描页作「璽」的字例。[教育部字典](https://dict.variants.moe.edu.tw/dictView.jsp?ID=27957) · [CODH 释字](https://codh.rois.ac.jp/tensho/unicode/U%2B74BD/#TE00003) |
| 槜／檇 | 《说文广义》卷十第 45 页 4 条旧框均对应「檇」，原注引地名「檇李」。本次取安本春湖《新撰篆書字典》原页，检索标签使用「槜」，释文保留「檇」。[东京文化财研究所异体字表](https://www.tobunken.go.jp/archives/kanji-variant-list/) · [原书扫描页](https://dl.ndl.go.jp/pid/1181885/1/16) |
