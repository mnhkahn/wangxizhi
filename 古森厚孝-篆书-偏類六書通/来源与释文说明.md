# 古森厚孝《偏類六書通》

收录 55 张原书影像，共 64 个缺字字框。释文采用国文学研究资料馆收集、CODH 和 DHII 整理的《篆書字体データセット》逐字标签，原样保留简繁写法。每个字框以索引公布的 IIIF 页坐标为起点，将来源发布的单字原图与原页配准，再用项目像素投影算法复核位置。

[篆書字体データセット](https://codh.rois.ac.jp/tensho/)（[DOI 10.20676/00000390](https://doi.org/10.20676/00000390)，[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)）。释文定位表记录原页坐标和逐字索引。原书影像的提供机构和权利信息随清单中的 IIIF 原始编目保留。
